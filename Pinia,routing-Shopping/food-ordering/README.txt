ONLINE FOOD ORDERING - VUE ROUTER + PINIA

Requirements:
- Node.js and npm installed

Run:
1. Extract this ZIP.
2. Open the extracted food-ordering folder in VS Code.
3. Open the terminal in that folder.
4. Run:
   npm install
   npm run dev
5. Open the local URL printed by Vite (usually http://localhost:5173).

Pages:
- /       Home
- /menu   Food menu; add items to cart
- /cart   Change quantities, remove items, clear cart, view total

This is a FRONTEND-ONLY demonstration. It does not require Spring Boot,
MongoDB, MySQL, or a backend server. Cart state is in Pinia memory and
will reset if the page is fully reloaded.
